## Helpful Forum Drafts

### Percentage Question

```text
The easiest way to handle this is to name the two numbers first:

- original value
- new value

Percent change is usually:
(new value - original value) / original value x 100

So if something went from 80 to 100, the change is 20, and 20 / 80 x 100 = 25%.

I have a free browser calculator for this if you want to check examples:
https://accessfreetools.com/tools/percentage-calculator/
```

### Wallpaper Question

```text
Do not estimate wallpaper only from wall width and height. You also need roll coverage, pattern repeat, openings, and waste.

Waste percent is extra material for trimming, matching patterns, corners, and mistakes. A simple wall might need less waste, while a patterned wallpaper usually needs more.

I made a free calculator that shows the inputs clearly:
https://accessfreetools.com/tools/wallpaper-calculator/
```

### OCR Question

```text
OCR works best when the image is sharp, straight, and high contrast. It can struggle with handwriting, tiny text, glare, rotated photos, or decorative fonts.

For private quick checks, browser OCR can be useful because the text extraction happens in the browser after the OCR files load.

Here is a free tool I built for that:
https://accessfreetools.com/tools/image-to-text-ocr-tool/
```
