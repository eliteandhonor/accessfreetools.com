Source reviewed: Calculator.net sitemap on 2026-04-29. This is a competitor inventory reference only; Access Free Tools should write its own UI, formulas, FAQs, examples, and blog guides for every tool.

## Current Coverage Snapshot

- Sitemap utility-style entries reviewed: 203.
- Existing Access Free Tools coverage after aliases: 95.
- Remaining roadmap items: 108.
- Aliases already covered: IP Subnet -> Subnet, Common Factor -> Greatest Common Factor, Mortgage Amortization -> Amortization, Time Duration -> Time.

## New-Tool Standard

Every new tool should ship as a complete content unit:

- Research the formula, rules, limits, and safety notes before coding.
- Build the calculator or generator with private in-browser behavior where practical.
- Add plain-language FAQs that answer real user confusion, not generic filler.
- Add a blog guide that explains how to use the Access Free Tools version.
- Add examples, related tools, search metadata, sitemap coverage, and icon treatment.
- Run tests, build, and browser preview checks before release.
