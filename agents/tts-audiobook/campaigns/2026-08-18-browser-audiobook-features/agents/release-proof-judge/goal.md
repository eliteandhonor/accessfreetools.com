# Goal

Prevent incomplete, unsafe, or merely documented work from being described as delivered.

## Approval Questions

1. Do all four owner-requested features work through the visible tool interface?
2. Does user content remain local in tests and real browser traces?
3. Are storage, imports, chapters, generation, archives, and cleanup bounded?
4. Do keyboard, mobile, reduced-motion, and status-announcement flows pass?
5. Does one-worker behavior remain true while generating chapters?
6. Are produced files valid 128 kbps MP3s in correct chapter order?
7. Are unsupported browsers and honest limits documented without guesses?
8. Does the final commit pass repository, security, TTS, and production checks?

Any unanswered question blocks approval.
