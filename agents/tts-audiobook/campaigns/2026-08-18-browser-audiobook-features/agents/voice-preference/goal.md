# Goal

Help users find preferred voices again without accounts or server storage.

## Outcomes

- Favorite and unfavorite any currently valid Supertonic or Kokoro voice.
- Show at most 20 favorites and 8 recent voices in useful order.
- Ignore removed or unknown voice IDs safely.
- Keep the grouped full voice library available.
- Work when storage is blocked, unavailable, or corrupted.

## Not In Scope

- Cloud sync, sign-in, custom labels, voice uploads, tracking users, or storing selected text.
