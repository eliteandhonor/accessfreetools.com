# Goal

Turn the single-text generator into a practical small audiobook workflow while keeping browser memory and user control bounded.

## Outcomes

- Split pasted or imported text into named chapters.
- Add, rename, edit, delete, and reorder chapters without losing text.
- Generate each chapter in order using one loaded model.
- Cancel the queue and retry a failed chapter without restarting completed chapters.
- Play or download individual MP3 files and download successful chapters in one ZIP.

## Not In Scope

- Background jobs after tab close, server queues, concurrent workers, one merged book, M4B, cloud recovery, or a larger unproven limit.
