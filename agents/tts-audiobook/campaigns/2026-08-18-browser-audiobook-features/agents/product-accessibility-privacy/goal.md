# Goal

Make the four new features feel like one coherent browser tool while preserving the working TTS experience.

## Outcomes

- A clear flow from input or import, to chapter review, to voice choice, estimate, generation, playback, and download.
- No nested-card clutter, clipped controls, heading overlap, or horizontal overflow.
- Full keyboard use, meaningful labels, live progress, cancel/retry recovery, and reduced-motion behavior.
- No user content in network traffic, analytics, logs, error telemetry, or Clarity.
- Clean workers, audio URLs, imported bytes, and archive buffers after cancellation, replacement, download, and navigation.

## Not In Scope

- Redesigning unrelated pages, adding accounts, adding public sharing, or changing the model family.
