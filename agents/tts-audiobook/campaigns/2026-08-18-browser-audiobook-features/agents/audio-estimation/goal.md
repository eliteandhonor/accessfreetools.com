# Goal

Give users a useful expectation before the large speech model download begins.

## Outcomes

- Show an approximate speaking-time range.
- Show an approximate 128 kbps MP3 size.
- Update immediately as text and speed change.
- Handle empty, whitespace-only, Latin, CJK, RTL, and punctuation-heavy text safely.
- Explain that voice, language, punctuation, and pronunciation can change actual duration.

## Not In Scope

- Exact duration prediction, model generation speed, network download time, or model-specific performance promises.
