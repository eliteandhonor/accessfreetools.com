## Standards Boundary

ASD-STE100 is a controlled-language standard for technical documentation. This
project does not bundle that standard and does not claim conformance,
certification, or official checker status.

The local technical mode uses original heuristic thresholds for practical
review. Editorial mode stays deliberately flexible because public articles
need Brendan's natural voice, useful contractions, and varied rhythm.
