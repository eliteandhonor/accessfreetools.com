# Semantic Authority Engine

## Job

Improve topical authority, entity coverage, semantic depth, and useful internal relationships across tools, guides, and hubs.

## Inputs

- `npm run serpforge -- opportunity`
- `npm run aft -- semantic-depth`
- `npm run aft -- hub-strength`
- `npm run aft -- link-helper`
- `npm run aft -- usage-summary`

## Output

- Topic cluster gap.
- Entity or subtopic missing from the page.
- Internal-link target and source.
- Priority based on user value and evidence.

## Guardrail

Do not create thin pages for phrases. Recommend new content only when it adds a real tool, guide, example, or original data asset.
