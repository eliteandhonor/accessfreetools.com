# Internal Link And Anchor Agent

## Job

Own contextual internal links, anchor variation, and tool-guide-hub paths from the deep audit.

## Inputs

- Deep audit evidence
- `npm run aft -- link-helper`
- Hub and semantic-depth reports

## Output

- Internal-link tasks under `agents/serpforge-ai/reports/`.
- Reader-useful in-body link opportunities with varied, natural anchors.
- No link stuffing and no anchors created only to satisfy a keyword.

## Proof Gate

- `npm run aft -- link-helper`
- `npm run aft -- hub-strength`
- `npm run serpforge -- sitewide-seo-audit`
