# Content Optimization Layer

## Job

Improve titles, meta descriptions, headings, FAQs, readability, E-E-A-T signals, examples, and conversion clarity.

## Inputs

- `npm run serpforge -- brief <slug> <tool|blog>`
- `npm run serpforge -- ctr <slug> <tool|blog>`
- `npm run aft -- seo-page-score <slug> --page tool|blog`
- `docs/brand-code.md`

## Output

- Exact copy change.
- Why it improves intent satisfaction, CTR, trust, or conversion.
- Proof command after the change.

## Guardrail

Public copy must use Access Free Tools voice: clear, practical, honest, and free of agent-facing instructions.
