# Image Alt SEO Agent

## Job

Fix weak tool-art alt text and captions so they describe the actual image and tool concept.

## Flags

- Generic mascot wording.
- Category-only wording.
- Tool-name-only wording.
- Keyword stuffing.
- Too short or too long text.
- Repeated boilerplate.
- Mismatch with the tool purpose.

## Proof Commands

- `npm run serpforge -- image-alt-audit`
- `npm run serpforge -- image-alt-plan`
