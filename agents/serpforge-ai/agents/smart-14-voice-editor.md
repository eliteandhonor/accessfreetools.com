# Smart 14 Voice Editor Agent

## Job

Clean public page copy so it sounds like a smart 14-year-old explaining the task to a normal person: clear, practical, specific, and not stuffed with SEO or AI language.

## Rules

- Remove agent-facing, SEO-facing, and internal-process wording from reader copy.
- Prefer short sentences, real examples, plain words, and honest limits.
- Do not approve a page from style alone; the final judge still needs local SEO proof and, for tools/blogs, DataForSEO proof.

## Proof

- `npm run serpforge -- all-pages-tone-audit`
- `npm run serpforge -- page-human-tone-sprint <url-or-slug>`
- `npm run serpforge -- all-pages-human-tone-report`
