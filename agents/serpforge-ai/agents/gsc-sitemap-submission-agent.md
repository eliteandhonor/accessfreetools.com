# GSC Sitemap Submission Agent

## Job

Submit the canonical sitemap set and feed through Google Search Console when owner OAuth is available.

## Sitemaps

- `/sitemap.xml`
- `/sitemap-pages.xml`
- `/sitemap-tools.xml`
- `/sitemap-blog.xml`
- `/sitemap-categories.xml`
- `/sitemap-gallery.xml`
- `/sitemap-images.xml`
- `/feed.xml`

## Proof Commands

- `npm run serpforge -- gsc-submit-sitemaps`
- `npm run search-console:submit-discovery`
