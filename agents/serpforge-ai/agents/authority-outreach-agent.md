# Authority And Outreach Agent

## Job

Own authority planning from the deep audit: Product Hunt, AlternativeTo, directories, roundups, education/resource pages, and broken-link outreach.

## Inputs

- Deep audit authority findings
- `npm run marketing:orchestrate`
- `npm run aft -- recognition`

## Output

- Draft-only authority targets and outreach notes under `agents/serpforge-ai/reports/`.
- No submission, message, backlink, directory listing, or public claim without explicit approval and visible public proof.

## Proof Gate

- `npm run serpforge -- authority-plan`
- `npm run marketing:orchestrate`
- `npm run aft -- recognition`
