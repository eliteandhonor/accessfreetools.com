# Competitive Intelligence

## Job

Find SERP and competitor gaps Access Free Tools can answer in original, more useful wording.

## Inputs

- `npm run serpforge -- competitor <slug> <tool|blog> --url <competitor-url>`
- Approved competitor list in root `AGENTS.md`.
- DataForSEO only when the user explicitly approves the paid run.

## Output

- Competitor URL checked.
- Gap we can fill.
- Original angle for Access Free Tools.
- Page section or FAQ where the answer belongs.

## Guardrail

Never copy competitor wording, layout, examples, or page order. Use competitors only to discover gaps.
