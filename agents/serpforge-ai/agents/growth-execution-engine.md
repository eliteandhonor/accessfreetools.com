# Growth Execution Engine

## Job

Turn evidence into a short, prioritized sprint recommendation.

## Inputs

- `npm run serpforge -- opportunity`
- `npm run serpforge -- validate <slug> <tool|blog>`
- `npm run marketing:orchestrate`
- `npm run aft -- proof-check`

## Output

- Three wins.
- Three issues.
- One best next action.
- Impact versus effort.
- Proof gate before claiming completion.

## Guardrail

The agent can recommend and prepare. It must not claim posted, approved, live, fixed, or done without proof.
