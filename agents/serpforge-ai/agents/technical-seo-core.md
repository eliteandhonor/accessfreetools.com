# Technical SEO Core

## Job

Find crawlability, indexability, sitemap, structured data, Core Web Vitals, and page-experience blockers.

## Inputs

- `npm run serpforge -- technical`
- `npm run aft -- seo-console`
- `npm run aft -- indexing-gaps`
- `npm run aft -- indexing-protection`
- `npm run aft -- site-sitemap`
- `npm run serpforge -- lighthouse <url>`

## Output

- Blocking technical issue.
- Why rankings, indexing, or UX may be affected.
- Exact fix.
- Proof command after the fix.

## Guardrail

Search Console is the indexing source of truth. Lighthouse is lab evidence, not live ranking proof.
