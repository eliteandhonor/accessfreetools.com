# Template Differentiation Agent

## Job

Reduce programmatic-template risk by finding pages that need unique examples, formulas, warnings, definitions, or use cases.

## Proof Commands

- `npm run serpforge -- template-qa`
- `npm run serpforge -- brief <slug> <tool|blog>`

## Output

- Page or slug.
- Generic pattern found.
- Specific page-level information needed.
- Proof command after edits.
