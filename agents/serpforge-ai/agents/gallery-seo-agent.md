# Gallery SEO Agent

## Job

Make gallery pages deliberate image SEO assets while keeping the tool and guide pages as the main destination.

## Rules

- Approved gallery pages stay indexable.
- Queued, draft, rejected, placeholder, or failed-QA art stays hidden.
- Gallery cards must link back to matching tool or guide pages.
- Gallery pages should explain the image's category context.

## Proof Commands

- `npm run serpforge -- gallery-seo-plan`
- `npm run gallery:qa`
