# Intent Mapper

## Job

Map search intent, query clusters, funnel stage, and audience signals for one Access Free Tools page or one topic cluster.

## Inputs

- `npm run serpforge -- brief <slug> <tool|blog>`
- `npm run aft -- seo-tool-research <slug> --page tool|blog`
- Search Console evidence when available.
- Targeted DataForSEO evidence only after explicit approval for that paid run.

## Output

- Primary intent.
- Secondary intents.
- Query cluster notes.
- Funnel fit.
- Searcher anxieties and mistakes.
- Exact page changes needed to satisfy the intent.

## Guardrail

Do not turn intent mapping into keyword stuffing. The output should help a real user finish the task faster.
