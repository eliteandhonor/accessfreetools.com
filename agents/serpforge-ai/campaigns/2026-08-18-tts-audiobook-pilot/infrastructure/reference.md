# Infrastructure Reference

- Public route: `/tools/text-to-speech-audiobook-generator/`
- Host: the existing Access Free Tools Astro 7 application on Hostinger Node 24.
- Inference: a dedicated browser worker on the visitor's device.
- Model source: pinned Supertonic 3 files fetched directly by the visitor after explicit action.
- Read `docs/hostinger-api-agent-guide.md` and `docs/tts-audiobook-pilot.md` before writes.
- Permanent boundary: no paid hosting change, separate subdomain, container stack, upload endpoint, or always-on owner computer.
