# Release Judge Reference

Approval layers are separate:

1. Local code, dependency, parser, and model-pin readiness.
2. Local browser generation, network-boundary, visual, and accessibility proof.
3. Noindex deployment to the existing Hostinger Astro site on Node 24.
4. Seven stable browser-beta days across supported devices.
5. Public live proof and only then indexability and discovery submission.

Any requirement for a purchase, separate host, DNS change, server inference, or owner-PC uptime is an automatic rejection.
