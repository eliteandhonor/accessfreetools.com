# Security And Privacy Reference

- Source text and filenames stay in browser memory and are not uploaded to Access Free Tools.
- Generated WAV data stays in a browser object URL until replaced, stopped, or the page closes.
- Network requests after user action are limited to pinned model configuration, ONNX, and selected voice files.
- Analytics may record text-free model-ready, generation, completion, cancellation, and download actions only.
- Input, chapter, status, and audio surfaces must be masked from Microsoft Clarity.
- EPUB parsing rejects unsafe paths, excessive expansion, scripts, and remote resources.
