# Brendan Editorial And Promotion Campaign

This campaign coordinates owner-led editorial and promotion work from 2026-08-08 through 2026-09-23.

## Active Channels

- Access Free Tools blog: primary canonical publication.
- Medium: original owner stories and selected canonical companions.
- Bluesky: practical owner notes and article releases.
- Pinterest: fresh visual discovery assets linked to exact site pages.

Quora is retired, Reddit is blocked, LinkedIn is not in use, Flipboard is unverified/inactive, and every other platform is outside this campaign.

## Status Rules

Use `planned`, `in_progress`, `evidence_ready`, `approved`, or `blocked`. Only the Release and Proof Judge may set `approved`. A submit button, local draft, or generated asset is not public proof.

## Operating Order

1. Evidence Intake records current source and platform proof.
2. Brendan Voice prepares useful first-person copy.
3. Distribution runs the channel gate and performs the authorized action.
4. Release and Proof Judge checks the public URL or public profile view before approval.

The completed 604-unit generated tool/guide queue is outside this campaign and must remain unchanged.
