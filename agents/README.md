# Agent Workspaces

This folder holds private repo-local workspaces for named specialist agents. These are working areas, not public site content.

Current workspaces:

- `serpforge-ai/`: SERPForge AI SEO persona workspace for strategy notes, evidence, briefs, and SEO execution reports.
- `tts-audiobook/`: Browser-only Text to Speech Audiobook Generator product campaign, feature-owner goals, privacy boundaries, and release proof.
